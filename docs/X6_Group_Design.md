# X6 多节点组合功能（Group/Combo）详细设计文档

## 一、功能概述

基于 antv X6 的 `Group` 机制实现多节点组合功能，支持将多个节点/边组合为一个逻辑整体，同时保留子节点的独立编辑能力。组合后对外表现为单一容器节点，对内维持完整的子节点操作空间。

---

## 二、组合具备的核心功能

### 2.1 创建组合

| 触发方式 | 说明 | 边界条件 |
|---------|------|---------|
| **框选创建** | 框选多个节点后，点击"组合"按钮或按 `Ctrl/Cmd + G` | 仅选中节点数 ≥ 2 时可用；若选中边，边**不纳入**组合，仅作为关联保留 |
| **右键菜单** | 多选后右键选择"创建组合" | 同上 |
| **API 创建** | `graph.createGroup(cells, options)` | 支持传入 `cells` 数组，自动过滤不可组合元素（如已属于其他组合的子节点需先解组） |
| **拖拽成组** | 将节点拖入已有组合区域（碰撞检测） | 需开启 `embedding: true`，且目标组合需设置 `droppable: true` |

**创建时行为：**
- 自动生成 Group 节点（默认矩形，透明填充，带虚线边框）
- 子节点 `parent` 属性指向 Group ID
- Group 的 `children` 数组记录子节点 ID 列表
- 自动计算并设置 Group 的 `size` 与 `position` 为所有子节点的包围盒（BBox）+ padding（默认 16px）
- 若子节点已有 `parent`，拒绝组合或提示先解组（根据配置策略）

### 2.2 组合选中与视觉反馈

| 状态 | 视觉表现 | 交互行为 |
|-----|---------|---------|
| **单选组合** | Group 边框高亮（主色），子节点边框次级高亮（透明度 50%） | 点击 Group 空白区域选中整个组合 |
| **多选（含组合）** | Group 作为整体参与多选，显示统一的多选框 | 子节点不单独显示选中态，避免视觉混乱 |
| **悬停** | Group 边框加粗，显示"组合"文字标签（左上角） | 子节点悬停时显示各自 tooltip |

**关键规则：**
- 点击组合内子节点：默认**不穿透**选中子节点，而是选中整个组合（需双击或特定模式才能进入子节点编辑）
- 点击组合边框：选中组合本身，可调整组合大小（影响子节点相对位置）

### 2.3 组合移动

| 场景 | 行为 | 边界条件 |
|-----|------|---------|
| **拖动 Group** | 所有子节点同步移动，保持相对位置不变 | 若子节点被 `restricting` 限制，以子节点边界为准，Group 移动受约束 |
| **键盘方向键微调** | 整体平移，步长遵循画布配置 | 子节点若锁定（`locked: true`），组合仍可移动，但锁定子节点相对位置不变 |
| **多选拖动（含组合）** | 组合作为整体参与移动，内部结构不变 | 若多个组合嵌套，仅移动最外层被选中的组合 |

### 2.4 组合缩放与旋转

| 操作 | 行为 | 边界条件 |
|-----|------|---------|
| **缩放 Group** | 子节点同步缩放（矩阵变换），保持相对比例 | 子节点若设置 `resizable: false`，不参与缩放，但位置仍跟随 Group 变换 |
| **旋转 Group** | 子节点同步旋转，保持相对角度 | 同上；旋转后子节点的 `angle` 属性更新为绝对角度（Group.angle + 相对 angle） |
| **子节点独立缩放** | 进入编辑模式后可独立调整 | 退出编辑模式后，Group 重新计算包围盒 |

### 2.5 组合样式与配置

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| `groupPadding` | 16 | 组合内边距，影响自动计算的包围盒 |
| `groupFill` | `rgba(0,0,0,0.02)` | 组合背景色，建议极低透明度 |
| `groupStroke` | `#d9d9d9` | 组合边框色 |
| `groupStrokeDasharray` | `4 4` | 虚线样式，区分普通节点 |
| `groupCollapsible` | false | 是否支持折叠（收起子节点，仅显示 Group） |
| `groupDroppable` | true | 是否允许拖入新节点 |

### 2.6 组合层级（Z-Index）

| 规则 | 说明 |
|-----|------|
| **整体层级** | Group 作为一个节点参与层级排序，调整 Group 的 `zIndex` 会带动所有子节点 |
| **内部层级** | 子节点在 Group 内部可独立调整 `zIndex`，但始终受 Group 层级约束（子节点实际渲染层级 = Group.zIndex + 子节点相对 zIndex） |
| **跨组合层级** | 两个 Group 之间的层级关系由 Group 自身 zIndex 决定，内部子节点不直接参与全局排序 |

### 2.7 组合与边（Edge）的处理

| 场景 | 行为 |
|-----|------|
| **组合内节点连线** | 边正常连接两个子节点，视觉上完全在 Group 内部 |
| **跨组合连线** | 边连接 Group A 的子节点与 Group B 的子节点，边显示在 Group 上方（zIndex 取两者较高者 + 1） |
| **组合与独立节点连线** | 正常连接，边显示在 Group 上方 |
| **Group 作为连接点** | 支持将 Group 整体作为 source/target（需配置 `magnet: true` 在 Group 边框） |

## 三、编辑子节点的方式

### 3.1 进入子节点编辑模式（Edit Mode）

| 触发方式 | 操作 | 视觉反馈 |
|---------|------|---------|
| **双击 Group** | 双击组合空白区域 | Group 边框变为实线 + 蓝色，背景透明度增加，显示"编辑中"标签 |
| **快捷键** | 选中 Group 后按 `Enter` 或 `F2` | 同上 |
| **右键菜单** | "进入编辑模式" | 同上 |
| **API** | `group.enterEditMode()` | 同上 |

**编辑模式下的画布行为：**
- 画布其他区域（非当前 Group 内）置灰或降低透明度（`opacity: 0.3`），突出当前编辑区域
- 当前 Group 的 `zIndex` 临时提升至最高（如 `9999`），确保子节点操作不被遮挡
- 其他 Group 的交互被禁用（`pointer-events: none`）

### 3.2 编辑模式内的操作

| 操作 | 行为 | 边界条件 |
|-----|------|---------|
| **单选子节点** | 正常选中、移动、缩放、旋转 | 子节点不可移出 Group 边界（若 `restricting: 'parent'`） |
| **多选子节点** | 框选或 `Shift + 点击` 多选 Group 内子节点 | 多选后可在 Group 内创建**子组合**（嵌套组合） |
| **新增节点** | 从组件库拖拽到 Group 内，自动成为子节点 | 若拖拽到 Group 外，则创建为独立节点 |
| **删除子节点** | `Delete` 键删除，Group 自动重新计算包围盒 | 若删除后 Group 内无节点，按配置决定是否自动解散 |
| **修改属性** | 属性面板显示子节点属性，正常编辑 | 实时同步 |
| **子节点连线** | 正常创建边，若两端都在 Group 内，边显示在 Group 内 | 若一端在 Group 外，边显示在 Group 上方 |

### 3.3 退出编辑模式

| 触发方式 | 操作 | 行为 |
|---------|------|------|
| **双击空白** | 双击 Group 外画布区域 | 退出编辑，Group 重新计算包围盒 |
| **快捷键** | `Esc` | 同上 |
| **点击父级** | 点击外层 Group（嵌套场景） | 退出当前 Group，进入父 Group 编辑模式或仅选中父 Group |
| **API** | `group.exitEditMode()` | 同上 |

**退出时行为：**
- 若子节点位置/大小变化导致超出原 Group 边界，Group 自动扩展包围盒（带动画过渡）
- 若子节点被移出 Group 区域（且配置允许），则自动从 Group 中移除该子节点，更新 `children` 数组
- 恢复画布正常交互状态

### 3.4 子节点属性面板编辑（非编辑模式）

| 场景 | 行为 |
|-----|------|
| **选中 Group 时属性面板** | 显示 Group 自身属性（尺寸、位置、样式、数据） |
| **选中子节点时属性面板** | 需先进入编辑模式，否则点击子节点仅选中 Group |
| **快捷编辑** | 支持在属性面板中列出子节点列表，点击列表项可直接跳转编辑模式并选中该子节点 |

## 四、取消组合（Ungroup）方式

### 4.1 完全解散

| 触发方式 | 操作 | 结果 |
|---------|------|------|
| **快捷键** | 选中 Group 后按 `Ctrl/Cmd + Shift + G` | Group 节点删除，所有子节点提升为独立节点，保留当前世界坐标 |
| **右键菜单** | "取消组合" | 同上 |
| **API** | `graph.ungroup(groupId)` | 同上；支持批量 `graph.ungroup([id1, id2])` |

**解散时行为：**
- 子节点 `parent` 属性置空
- 子节点 `zIndex` 更新为原 Group.zIndex + 相对 zIndex（或统一设置为 Group.zIndex，可配置）
- 若 Group 有样式（如背景色、边框），解散后子节点不继承 Group 样式
- 若 Group 被折叠（collapsed），先展开再解散

### 4.2 提取子节点

| 触发方式 | 操作 | 结果 |
|---------|------|------|
| **拖拽提取** | 在编辑模式下将子节点拖出 Group 区域 | 该子节点从 Group 中移除，成为独立节点 |
| **右键提取** | 右键子节点选择"从组合中移除" | 同上 |
| **API** | `group.removeChild(childId)` | 同上；Group 自动重新计算包围盒 |

### 4.3 嵌套组合解散

| 场景 | 行为 |
|-----|------|
| **解散父 Group** | 父 Group 删除，子 Group 提升为独立 Group（保留其内部结构） |
| **递归解散** | 配置 `recursive: true` 时，解散父 Group 同时递归解散所有子 Group |
| **多层嵌套选中** | 仅解散当前选中的 Group 层级，不影响上下层 |

## 五、功能边界与边界条件

### 5.1 嵌套层级限制

| 边界 | 策略 |
|-----|------|
| **最大嵌套深度** | 默认限制 5 层，超过时禁止创建新组合或拖入（可配置 `maxGroupDepth`） |
| **循环引用** | 禁止将 Group A 拖入 Group B，如果 Group B 已经是 Group A 的子孙（通过 `parent` 链检测） |
| **自组合** | 禁止选中 Group 自身与其子节点一起创建新组合（选中列表过滤掉父 Group） |

### 5.2 空组合与最小尺寸

| 边界 | 策略 |
|-----|------|
| **空 Group 处理** | 删除最后一个子节点后，若配置 `autoRemoveEmptyGroup: true`，自动删除 Group；否则保留空 Group（显示占位符） |
| **最小尺寸** | Group 自动计算的最小尺寸为 40×40px（即使子节点更小），防止无法选中 |
| **子节点全删除** | 解散或删除后，空 Group 可继续添加新节点（若未自动删除） |

### 5.3 跨画布/跨页面边界

| 边界 | 策略 |
|-----|------|
| **复制组合** | `graph.copy(groupId)` 时，同时复制 Group 及其所有子节点，保持内部结构，新 ID 映射 |
| **剪切/粘贴** | 跨画布粘贴时，若目标画布已存在相同 ID 的子节点，自动重命名并更新 `parent` 引用 |
| **序列化/反序列化** | `toJSON()` 时 Group 与子节点一并导出；`fromJSON()` 时先创建子节点，再创建 Group 并绑定 `parent` |

### 5.4 性能边界

| 边界 | 策略 |
|-----|------|
| **大组合（>100 子节点）** | 移动/缩放时开启 `async: true` 或 `debounce`，避免频繁重绘；编辑模式下子节点超过 50 个时，非选中子节点降级为图片缓存 |
| **大量组合** | Group 的 `visible` 属性控制显示/隐藏，折叠时子节点从 DOM 移除（`display: none`） |
| **动画性能** | Group 展开/折叠、进入/退出编辑模式使用 CSS transition，避免 JS 逐帧计算 |

### 5.5 撤销重做（Undo/Redo）

| 边界 | 策略 |
|-----|------|
| **组合操作原子性** | 创建组合 = 一个原子操作（包含创建 Group + 更新所有子节点 parent）；撤销时整体回退 |
| **编辑模式内操作** | 编辑模式内的子节点移动/缩放等操作，正常进入 Undo 栈；退出编辑模式本身也作为一个操作记录 |
| **解散原子性** | 解散 Group = 删除 Group + 所有子节点 parent 置空，撤销时恢复完整结构 |

### 5.6 交互边界

| 边界 | 策略 |
|-----|------|
| **Group 锁定** | Group 设置 `locked: true` 时，整体不可移动/缩放，但可进入编辑模式操作子节点（若 `locked` 仅限制 Group 自身变换） |
| **子节点锁定** | 子节点锁定后，在编辑模式下仍可见，但不可单独移动/删除；Group 整体移动时，锁定子节点跟随移动 |
| **只读模式** | 画布 `readonly: true` 时，禁止创建/解散组合，禁止进入编辑模式，仅支持查看 |

### 5.7 边与组合的边界

| 边界 | 策略 |
|-----|------|
| **边穿过 Group** | 边连接两个独立节点但路径穿过 Group 区域，视觉上边显示在 Group 上方（zIndex 规则），不纳入 Group |
| **Group 内边导出** | 若 Group 折叠，内部边隐藏；若边一端在 Group 内一端在外，折叠时显示为 Group 上的连接桩（port）引出 |

## 六、状态机与数据结构设计

### 6.1 Group 节点数据模型

```typescript
interface GroupNodeData {
  id: string;
  shape: 'group';           // X6 自定义节点 shape
  parent?: string;          // 父 Group ID（支持嵌套）
  children: string[];      // 子节点 ID 列表（有序）

  // 组合配置
  collapsible?: boolean;    // 是否可折叠
  collapsed?: boolean;      // 当前折叠状态
  droppable?: boolean;      // 是否允许拖入
  padding?: number;         // 内边距

  // 编辑状态（运行时，不持久化）
  editing?: boolean;        // 是否处于编辑模式
  originalZIndex?: number;  // 进入编辑模式前的 zIndex

  // 样式
  attrs: {
    body: {
      fill: string;
      stroke: string;
      strokeDasharray: string;
      // ...
    }
  }
}
```

### 6.2 子节点数据模型

```typescript
interface ChildNodeData {
  id: string;
  parent: string;           // 所属 Group ID
  // ... 普通节点属性
}
```

### 6.3 状态机

```
[选中 Group] --双击/Enter/F2--> [编辑模式]
[编辑模式] --Esc/双击空白/exitEditMode()--> [选中 Group]
[编辑模式] --拖拽子节点出边界--> [子节点独立 + Group 重新计算]
[选中 Group] --Ctrl+Shift+G/ungroup()--> [解散，子节点独立]
[选中 Group] --Ctrl+G（选中含其他节点）--> [创建新 Group（嵌套）]
```

## 七、API 设计草案

```typescript
// 创建组合
graph.createGroup(cells: Cell[], options?: GroupOptions): Group

// 解散组合
graph.ungroup(groupId: string | string[]): void

// 进入/退出编辑模式
group.enterEditMode(): void
group.exitEditMode(): void

// 子节点管理
group.addChild(cellId: string): void
group.removeChild(cellId: string): void
group.getChildren(): Node[]
group.getDescendants(): Node[]  // 递归获取所有子孙

// 折叠/展开
group.collapse(): void
group.expand(): void
group.toggleCollapse(): void

// 工具方法
graph.isDescendant(parentId: string, childId: string): boolean  // 判断是否子孙关系
graph.getGroupDepth(groupId: string): number  // 获取嵌套深度
```
